## Goal

Build the Alper Marble Catalog page at route `/catalog`: a Hebrew/RTL page that presents
the memorial-stone offering as a two-column layout — a grid of 4 material/design category
cards (content, right-to-left) plus a sidebar of category/style/price filters (left) — with
a breadcrumb above and pagination below. Each category card links forward toward its
gallery/detail view. Reuses the shared `Header` and `Footer` already built for the Homepage.
No cart, checkout, or payment UI (PRD F5 / AC-4).

## Assumptions

## Open Questions

1. **Where should each category card's `לצפייה בגלריה` link point?** The Product
   Detail / gallery page does not exist yet.
   *Recommended:* create minimal stub routes at `frontend/src/app/catalog/[slug]/page.tsx`
   (placeholder heading only) and link cards to `/catalog/<slug>` (e.g.
   `/catalog/turkish-marble`) so links don't dead-end (PRD AC-1); the Product Detail backlog
   task fully implements them. If stubs are undesirable now, fall back to `#` with a code
   comment. **Recommend the stub route.**
2. **Are the sidebar filters, price slider, and pagination interactive in this task?**
   *Recommended:* No — render them **visual-only / non-interactive** (checkboxes present but
   not wired, slider static, pagination buttons non-navigating), matching the existing
   visual-only language switcher. Functional behavior is deferred until a catalog data source
   exists. Use proper `label`/`input` markup with `disabled` + `aria` for accessibility.
3. **Brand-label consistency:** the shared `Header` renders `שיש אלפר`, while this Figma
   frame's header/footer show `אלפר מצבות`.
   *Recommended:* keep the shared `Header`/`Footer` as-is for cross-page consistency (do not
   fork copy per page); treat the Figma label as a non-blocking design nit to flag to the
   designer separately.
4. **Result-count text `מציג 4 קטגוריות נבחרות`:** hard-coded string vs. derived from the
   categories array length. *Recommended:* derive from the array length so it stays correct
   if the list changes.

   - `שיש טורקי` (slug `turkish-marble`) — `שיש לבן איכותי, עמידות לשנים וסגנון קלאסי-מסורתי.`

   - `מצבות אבן גרניט` (slug `granite`) — `חוזק בלתי מתפשר, מראה יוקרתי ומבחר צבעים - שחור, אפור, אדום וכחול.`
   - `מצבות מיוחדות` (slug `special`) — `שילוב אבני לקט, עיצובים אמנותיים ופיסול אישי המשקף את דמותו של הנפטר.`

7. Create minimal stub route `frontend/src/app/catalog/[slug]/page.tsx` (placeholder heading

8. Use placeholder imagery for the 4 category cards
   (`// TODO: replace with client-provided photography`); do not download Figma asset URLs.
9. Confirm no cart/checkout/payment UI is introduced anywhere (PRD F5 / AC-4).
10. Write unit tests (Vitest + RTL): `CatalogGrid` (renders 4 categories, headings, links,

## Risks

- Hebrew serif font fallback may shift text metrics vs. Figma pixel measurements —
  acceptable variance, not pixel-matching. accept
- Placeholder imagery means shipped cards won't match Figma stock photos until real
  photography is swapped in. accept
- Visual-only filters/pagination could read as functional to users; keep affordances clearly
  non-active (disabled state / no hover-nav) to avoid confusion. accept
- Category-card link target (`/catalog/[slug]` stubs) must not conflict with the future
  Product Detail backlog task — keep stubs minimal placeholders only. accept
- Header/Footer brand-label mismatch (`שיש אלפר` vs `אלפר מצבות`) left as-is for
  consistency; designer sign-off pending. accept
